# ai-enterprise-template

A reusable template for a one-operator AI software enterprise inside Claude Code:
tool-locked role subagents (triage, spec, test, implement, review) build and check,
deterministic hook gates keep a human in the merge seat, and a behavior-first TDD loop
ties it together. The founder specifies and decides; the roles build; the gates hold
the line. Reuse this template to start future products.
