# ai-enterprise-template

A reusable template for a one-operator AI software enterprise inside Claude Code.
Tool-locked role subagents (triage, spec, test, implement, review) build and check;
two deterministic hook gates keep agents out of the merge seat; a vendored
behavior-first TDD harness and a GitHub-native sprint workflow tie it together. The
founder specifies and decides; the roles build; the gates hold the line.

See `CLAUDE.md` for the handbook (the constitution) and `docs/` for the decision log
and progress tracker.
