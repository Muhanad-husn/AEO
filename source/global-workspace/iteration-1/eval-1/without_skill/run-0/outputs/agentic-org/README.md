# ai-enterprise-template

A reusable template for a one-operator AI software enterprise inside Claude Code.
Tool-locked role subagents triage, spec, author tests, implement, and review; two
deterministic hook gates make the boundary real (agents never merge, no one commits a
red suite); a vendored behavior-first TDD harness and a GitHub-native sprint workflow
tie it together. The founder specifies, decides, and merges.

See `CLAUDE.md` for the handbook and `docs/` for the decision log and progress tracker.
