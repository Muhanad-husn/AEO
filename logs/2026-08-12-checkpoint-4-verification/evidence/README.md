# Checkpoint 4 evidence — clause 1, stage 0

The raw evidence behind clause 1 of [the Checkpoint 4 record](../summary.md): the
review packet the reviewer was given, and the review it returned.

`packet/` is the nine-file packet staged for branch `cp4/stage-0-mismatch` in the
testbed — the claim, the diff, the issue and spec section, the prior recorded
evidence, the test file, the post-change source, and the suite re-run at staging.
The numbered filenames are the packet's own ordering and carry meaning, so they are
preserved. `cp4-stage0-review.txt` sits outside `packet/` because it is the
reviewer's output rather than part of the input it was handed, and because
`packet/00-manifest.md` describes a packet of a fixed size that a tenth file would
contradict.

Everything here is a verbatim capture of the 2026-08-12 run, copied into the
repository on 2026-08-13 and unedited. The absolute `D:\aeo-testbed\...` paths
inside these files are what the run actually printed and are left as they were
printed.

Nothing reads this directory. It is a record, not a fixture — no test, hook, or
script loads it, and changing it changes no behaviour.
